# unMotion stable installer

This branch serves the stable Unraid installer for **unMotion 0.4.3** (Plugins-tab version **2026.10.04.01-0.4.3**). Requires Unraid 7.3.2 or later.

Install or update using [unmotion.plg](https://raw.githubusercontent.com/rtho782/unmotion/plugin-stable/unmotion.plg). It downloads the versioned TXZ release asset and verifies SHA-256, retaining the current package for offline boots and pruning older cached downloads after successful registration.

Read the [user guide](https://github.com/rtho782/unmotion-community-apps/blob/main/README.md), [release notes](https://github.com/rtho782/unmotion/releases/tag/0.4.3) and [upgrade guidance](https://github.com/rtho782/unmotion/blob/main/docs/SECURITY-042.md). Protocol 7 is unchanged from 0.4.2. Upgrading from 0.4.1 or earlier requires coordinated maintenance on both peers.
