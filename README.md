# unMotion published beta update feed

Author: Richard Skinner

This branch contains the published update descriptor for installations following the beta feed. During stable graduation it offers the stable release; installing that descriptor selects future stable updates.

The unmotion.plg file must be byte-identical to the descriptor attached to its versioned GitHub release or prerelease. Development commits do not advance this channel.

Source, documentation and release assets: https://github.com/rtho782/unmotion/releases
