#### unMotion

Clone virtual machines, migrate them between paired Unraid hosts with Cold or Warm Move, and maintain scheduled ZFS replicas with guarded manual recovery.

Keep verified backups and review migration and recovery preflight checks before proceeding. Warm Move requires a powered-off final cutover; live migration and automatic failover are not supported.
